# 本地曲库管理工具

## 安全边界

- 服务绑定 `127.0.0.1`，不接受局域网访问。
- 页面启动时获取随机会话令牌，写接口必须携带令牌。
- 请求来源和 `Host` 会被检查，服务不允许跨站调用。
- 文件名、作品 ID、版本 ID 和资源内容会在写入前校验。
- 保存先复制到临时目录并运行内容校验，通过后才替换作品目录。
- 不执行 Git 命令，不提交、不推送、不删除整个作品。

## API

服务默认端口为 `4317`，可以用 `ADMIN_PORT=4320 npm run admin` 修改。仓库根目录可以用 `SONG_ARCHIVE_ROOT=/path/to/repo npm run admin` 指定。

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| GET | `/api/session` | 获取当前页面会话令牌 |
| GET | `/api/works` | 读取索引摘要 |
| GET | `/api/works/{id}` | 读取作品、版本和编辑指纹 |
| POST | `/api/works` | 创建作品 |
| PUT | `/api/works/{id}` | 按编辑指纹更新作品 |
| GET | `/api/tags` | 读取标签目录和指纹 |
| PUT | `/api/tags` | 校验后更新标签目录 |
| POST | `/api/validate` | 在临时副本生成索引并校验内容 |

所有写请求使用 JSON。上传资源使用 `{ name, contentBase64 }`，服务器会把封面规范化为 `cover.<扩展名>`，歌词规范化为 `lyrics.txt`。

## 保存策略

编辑页面打开作品时记录作品目录指纹。保存时指纹不匹配会返回冲突，要求重新打开作品。版本文件会按当前页面的版本列表重写，已移除的版本文件不会继续保留；未替换的封面、歌词等资源会保留。
